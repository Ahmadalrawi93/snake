# Intelligence Layer — Design Notes

Planned stores:
- Episodic: findings, scan observations, and execution traces.
- Semantic: normalized technology and vulnerability knowledge.
- Procedural: reviewed methodologies and reusable test playbooks.

Retrieval must preserve provenance and confidence. Methodology suggestions remain drafts until reviewed and evaluated against a regression corpus. No self-modifying production prompts or automatic promotion of unverified discoveries.
